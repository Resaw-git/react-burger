## Общие принципы мобильной верстки

- Брейкпоинт: `max-width: 1279px` — мобильная версия, `>= 1280px` — десктоп (как сейчас в header/constructor).
- Макет рассчитан на 320px, контентная колонка 304px. Верстаем **резиной**: `width: 100%`, `max-width: 480px`, боковые отступы 16px (`padding: 0 16px`), чтобы на 375–768px контент не выглядел ужатым.
- Шапка мобильная: высота 64px (уже есть).
- Заголовок страницы: `mobile/display large` — JetBrains Mono Bold, 28px/32px, цвет `#F2F2F3`, выравнивание влево, отступ сверху от шапки 16px (y=80 на макете).
- Контент под заголовком: отступ ~24px (y=136 на формах).

### Общие компоненты

- Инпут: высота 48px, radius 40px, bg `--input-bg`, padding текста 20px; активный — border 2px `--accent`.
- Кнопка primary: gradient + glow, radius 32px, padding 10px 32px, текст mobile/text.
- Табы: padding 16px 40px; активный — `box-shadow: inset 0 -2px 0 #4C4CFF`, текст `#F2F2F3`; неактивный — `inset 0 -1px 0 #2F2F37`, текст `#8585AD`.
- Карточка заказа (mobile): bg `--modal-bg`, radius 40px, padding 16px, gap 16px, shadow `0 0 1px rgba(0,0,0,.04), 0 0 2px rgba(0,0,0,.06), 0 4px 8px rgba(0,0,0,.04)`.
- Превью ингредиента (mobile): круг 32×32, bg `--bg`, border 2px gradient, внутри картинка 56×28 со смещением x=-12, y=2; наложение друг на друга; «+N» — затемнение + текст.
- Полноэкранная «модалка»-страница: bg `--bg`, сверху title-бар (padding 16px 8px): заголовок display large слева + крестик 24×24 справа.


## Экраны по макетам

### 1. Логин (849:6017) — и по аналогии Register / ForgotPassword / ResetPassword
- Title «Вход», далее колонка gap 40px.
- Блок полей: gap 20px (E-mail, Пароль с иконкой глаза).
- Кнопка «Войти» — по центру.
- «additional actions»: колонка gap 20px, по центру; каждая пара — **в две строки**: серая строка-вопрос (`Вы — новый пользователь?`), под ней акцентная ссылка (`Зарегистрироваться`). То же для `Забыли пароль? / Восстановить пароль`.

### 2. Профиль (849:5997)
- Без левого меню (навигация через MobileMenu). Title «Профиль».
- Инпуты: Имя, Логин, Пароль — на всю ширину колонки, иконка карандаша справа.
- Кнопки «Сохранить» (primary) и «Отмена» (текстовая, accent) — **по центру, колонкой, gap 8px**; показывать **только когда изменён хотя бы один инпут** (isDirty).

### 3. История заказов (849:5980)
- Title «История заказов», без сайдбара.
- Карточки: шапка `#031295` (digits small) + дата справа в **две строки** (`17 дней назад,\n16:20 i-GMT+3`, secondary, 14/20, right).
- Название (display small, left) + статус: `Выполнен` — `--success`, `Отменен` — `--error`, `Готовится` — primary.
- Футер: превью ингредиентов 32px слева + цена (digits small + иконка) справа.

### 4. Лента заказов (849:6096 + 849:6106)
- Title «Лента заказов», под ним **табы «Заказы» / «Статистика»** (state-переключение секций).
- Секция «Заказы»: список карточек как в истории, но **без статуса**, дата `Сегодня,\n16:20 i-GMT+3`.
- Секция «Статистика» (gap 24px):
  - «Готовы:» / «В работе:» — две колонки по 140px в ряд, gap 24px; заголовки display small; номера digits small, gap 4px (готовы — `--success`).
  - «Выполнено за все время:» / «Выполнено за сегодня:» — заголовок display small + цифра **digits large 72/80**.

### 5. Модалка «Заказ оформлен» (849:6174)
- Полноэкранная, title-бар «Заказ оформлен» + крестик.
- Контент по центру (304px): номер заказа **digits large 72/90, цвет `--accent`, glow text-shadow**; подпись «идентификатор заказа» (display small, center); анимация done 120×120; «Ваш заказ начали готовить» (14/20); «Дождитесь готовности\nна орбитальной станции» (secondary, 14/20, 2 строки, center).

### 6. Ингредиент — прямая ссылка (849:6160)
- Полноэкранная страница, title-бар только с крестиком справа.
- Картинка 240×120 (object-fit cover), название (display small, center, до 2 строк), описание (14/20, center).
- КБЖУ — сетка **2×2** (две строки по два значения, gap 16px): подпись 14/20 + значение digits small, цвет secondary.

### 7. Детали заказа (849:6138)
- Полноэкранная, title-бар «Детали заказа» + крестик.
- `#034533` (digits small, left), название (display small), статус.
- «Состав:» — список: превью 32px + название (14/20, width ~144px) + справа `1 x 80` (digits small) + иконка валюты; строка padding 8px 0, gap 8px; скролл.
- **Нижняя фиксированная панель** (bg `--modal-bg`, padding 8px): дата слева (secondary), сумма + иконка справа.
